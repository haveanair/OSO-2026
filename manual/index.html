1. 참가자 사용법

  1. 현장 안내판의 실전판 QR을 스마트폰 기본 카메라로 촬영합니다.
  2. 게임의 시장 탐험에서 GPS 위치 확인 시작을 누르고 위치 권한을 허용합니다.
  3. 시장 안의 지정 GPS 구역에 도착하면 해당 게임이 자동 해금됩니다.
  4. GPS가 불안정하면 해당 세션의 현장 QR을 QR 보조 해금으로 읽습니다.
  5. 게임 기록과 해금 상태는 참가자의 브라우저에 저장됩니다.

모바일 GPS는 반드시 GitHub Pages의 https:// 주소로 접속해 사용합니다. 다운로드한 HTML을 content:// 또는 file://로 직접 열면 위치정보가 제한될 수 있습니다.

3. 보너스 게임

현장 게임 획득과 누적점수 조건을 달성하면 오소 우주파이터 · 오소레이싱 · 오소 환상대모험이 순차적으로 해금됩니다. 보너스 게임은 현장 QR이 아니라 게임 내 조건 달성형입니다.

4. GPS 운영

현장 해금 구역은 주차장 · 3구 어시장 · 2구통로 · 1구통로 · 뉴먹자골목 · 북쪽통로 · 2층 3구 비단길의 7곳입니다. 각 구역 안의 고정 GPS 해금 지점은 서로 겹치지 않도록 중앙시장 전체에 분산되어 있습니다. 시장 지붕과 건물 구조 때문에 GPS 오차가 커질 수 있으므로 실제 행사에서는 QR 보조 해금을 함께 준비합니다.

위치 권한을 거부한 참가자는 브라우저 사이트 설정에서 위치 권한을 다시 허용한 후 GPS 버튼을 다시 누릅니다.

5. 운영자 확인

🔓 전체해금판은 게임 내용과 GPS 보완은 실전판과 동일하고 모든 게임을 즉시 열어 현장 점검에 사용하는 버전입니다. 실전판과 저장키가 분리되어 서로의 진행 기록을 섞지 않습니다.
